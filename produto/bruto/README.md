## Por que este material vale mais que uma entrevista

Não é o usuário dizendo o que gostaria de ter. É o usuário **operando** um ambiente de
trabalho com IA montado à mão, com esforço suficiente para ter inventado a arquitetura
sozinho — orquestrador, sub-agentes, fábrica de agentes, contexto de longo prazo, separação
entre memória e estado, portões e rituais.

Evidência de comportamento, não opinião declarada. O que se extrai daqui são as dores que
a versão manual cobra — ver [`../dores.md`](../dores.md).

**Limite honesto:** por isso mesmo, nada aqui é uma dor *declarada* sobre ferramenta. Toda
dor destilada é inferência e precisa ser validada — ver [`../abertas.md`](../abertas.md), A-05.
