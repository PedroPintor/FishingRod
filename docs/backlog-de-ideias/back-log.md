
1. Formato Fishing Rod para a Criacao de Agentes

material de apoio: https://agentskills.io/specification

a ideia é ter um formato especifico para as criacoes de agentes do software Fishing Rod. O Fishing Rod vai ter um formato proprio de como criar agentes que sao mais inteligentes para o uso dentro do software.

A estrutura vai ser uma estrutura monolotico dentro de uma pasta. Uma pasta Significa todo um Agente para o Fishing Rod.

agente-fishing-rod/
├── AGENTE.md               # Required: metadata + instructions
├── REFERENCIAS_WIKI        # Required: links de refenrencia para a wiki([[wiki-referencia]])
├── 
├── conhecimentos/          # Optional: conhecimentos do agente
    └── index.md            # Required: sumario do conhcimento + descricao
├── resultados-validados/   # Required: resultados validos pelo usuario
