# Entrar no FishingRod com login

Estado: ideia
De onde veio: conversa do Pedro com a IA sobre a primeira tela, em 2026-10-20.

Ao abrir o FishingRod, vejo primeiro uma tela de entrada onde faço login, e só depois chego à tela
de início com os meus ambientes. Isso faz sentido quando o FishingRod tiver contas: cada pessoa vê
os próprios ambientes.

Hoje tudo é local e de uma pessoa só (ver a decisão [D06](../decisoes/D06-tudo-local.md)), então
o login ficou de fora da [primeira tela](primeira-tela.md). Uma tela de login de mentira chegou a
ser pensada para o começo, mas foi descartada: sem contas, ela não teria o que proteger.

Para pensar: o que é uma conta no FishingRod, se os ambientes passam a ser de uma conta e o que
muda com mais de uma pessoa usando o mesmo ambiente (o João e o Pedro).
