# Marca visual do software

Estado: ideia
De onde veio: conversa do Pedro com a IA ao terminar o card 003, em 2026-10-21.

Hoje as telas são só funcionais: nenhuma delas diz, visualmente, "isto é o FishingRod". A ideia é
dar ao software uma cara própria, bonitinha, nos dois lugares onde a pessoa entra:

- **Na tela inicial** (a lista de ambientes): um letreiro "FishingRod", com algum design — talvez
  com animação — em vez da lista aparecer sozinha.
- **Na tela do ambiente**: hoje o topo tem só a linha com o nome do ambiente, o mostrador de
  conexões do Claude e o botão "← ambientes". A ideia é pôr, acima dessa linha, algo visual com o
  nome do software.

Nada técnico decidido ainda: é para a IA, quando pegar isso, pensar num design a partir do que o
terminal (Textual) permite.
