# Criar um agente novo com o rod-maker

Estado: ideia
De onde veio: história de usuário US-11, escrita na fase do AI-DLC (tag `aidlc-congelado`).

Quando um trabalho se repete o bastante para merecer um agente próprio, peço ao orquestrador e
ele chama o rod-maker, um agente especial que constrói outros agentes. No fim, o agente novo
existe no ambiente e posso conversar com ele. Exemplos: um "qualificador de leads" para o João;
um "questionador" que testa o meu entendimento de uma matéria, para o Pedro.

Relacionadas: [formato próprio de agente](formato-de-agente.md) e a decisão
[D20](../decisoes/D20-lista-fixa-de-agentes.md).
