# Reaproveitar e melhorar uma tarefa que já fiz

Estado: ideia
De onde veio: história de usuário US-18, escrita na fase do AI-DLC (tag `aidlc-congelado`).

Quando um trabalho se repete (por exemplo, "resumir capítulo"), crio a tarefa nova
reaproveitando as etapas da anterior, em vez de definir tudo de novo. Se uma etapa me incomodou,
ajusto junto com o orquestrador, e o ajuste vale para a próxima vez.
